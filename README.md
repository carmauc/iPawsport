# iPawsport

Sitio web de iPawsport, un servicio de información, documentación y asesoramiento para viajar con perros y gatos.

> iPawsport no transporta animales ni vende o reserva vuelos. Los requisitos de viaje pueden cambiar; consulta siempre las fuentes oficiales, tu veterinario y la compañía de transporte.

## Tecnologías

- React
- Vite
- Tailwind CSS
- React Router
- i18next

## Requisitos

- Node.js y npm instalados.

## Instalación

Clona el repositorio y entra en la carpeta del proyecto:

```bash
git clone https://github.com/carmauc/ipawsport.git
cd ipawsport
```
"# iPawsport"
